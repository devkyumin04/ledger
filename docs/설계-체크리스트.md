# 설계 체크리스트

기능 하나가 끝날 때(QA 통과 직후, 커밋 전) 아래 항목에 대입한다.
`qa-체크리스트.md` 가 "동작이 맞는가" 라면 이 문서는 **"구조가 규칙대로인가"**.
케이스를 외우는 게 아니라 기준을 갖는 것이 목적. 대부분 grep 한 줄로 확인된다.

도구로 옮길 수 있는 항목은 표시해뒀다 — 포매터(지금), ArchUnit(Sprint 4 JUnit 때).
그 전까지는 사람이 본다.

---

## 1. 계층 역할 — 파일이 자기 층의 일만 하는가

| 층 | 해야 하는 것 | 하면 안 되는 것 | 확인 |
|---|---|---|---|
| domain | 테이블 컬럼 1:1, 상수 | 판단·계산 | 필드 외 메서드 없음 |
| dto | 값 담기 + 요청은 검증 애노테이션 | 로직 | `@Service`·매퍼 import 없음 |
| mapper | SQL, DB 가 잘하는 집계(SUM/GROUP BY) | 규칙 판단, 0 나누기 등 | XML 에 `<if>` 분기로 규칙 넣지 않음 |
| service | 소유권·규칙·파생값·트랜잭션 | HTTP 개념(상태코드, ResponseEntity) | `HttpStatus` import 없음 |
| controller | 입구 검증 + 상태코드 포장 | 판단·분기·매퍼 호출 | 매퍼 import 없음, if 문 없음 |

- 컨트롤러 메서드명 = 서비스 메서드명 (`getStatistics` ↔ `getStatistics`)
- **ArchUnit 후보**: controller → mapper 의존 금지, dto 패키지에 `@Service` 금지, service 에 `HttpStatus` 금지

## 2. 응답 DTO 애노테이션 (ADR-038)

- 서버가 만들어 채움 → `@Getter @AllArgsConstructor` (불변)
- MyBatis/Jackson 이 채움(요청 DTO, `*RowDto`) → `@Getter @Setter @NoArgsConstructor`
- 응답 DTO 를 MyBatis `resultType` 으로 직접 쓰면 후자 + **이유 주석** (현재 예외 1건: `PersonalTransactionResponseDto`)
- 요청 DTO 에 서버가 정하는 값(`userNum`, `transType`, `version`) 필드 없음 — Mass Assignment 방어
- **ArchUnit 후보**: `*ResponseDto` 에 setter 없음 (예외 목록 명시)

## 3. 서버 계산 · 뷰 표시 (ADR-038)

- 비율·파생값·"할 수 있다/없다" 는 서버가 응답 DTO 에 실어 보냄 (`isDefault`, `hasChildren`, `expenseRatio`, `balance`)
- 프론트에 예약어 리터럴 없음 — `grep -rn "'미분류'" static/js` = 0
- 프론트에 남겨도 되는 것: 포맷, 부호·색상, 정렬·그룹핑, 월 자리올림. **합산은 아님** (통계 API 값 사용)
- "계산 불가" 도 서버 판단 → `null` 로 내려보내고 프론트는 `-` 표시

## 4. 매퍼 (CLAUDE.md 규칙)

- `#{}` 만. `${}` 0건
- `@Param` 전부 (개수 무관)
- 조회 `WHERE use_yn = 'Y'` (users 는 `user_status`)
- 사용자 격리 — 목록 조회는 SQL 에 `user_num`, 단건은 서비스가 소유권 비교(403 구분용). 두 패턴 중 하나로 통일
- 거래 UPDATE 는 전부 `version = version + 1` (삭제·이관 포함)
- WHERE 에 컬럼 함수 금지 (`YEAR(trans_date)` ✗) — 날짜는 `[start, end)` 범위
- 반환 타입 — `WHERE` 조건 때문에 0행 가능하고 그걸 구분해야 하면 `int`, 아니면 `void` (ADR-025)

## 5. 입구 검증

- body → DTO 필드에 `@NotNull/@Min/...` + 컨트롤러 `@Valid`
- 쿼리스트링 → `@RequestParam` 파라미터에 직접 (`month` 의 `@Min(1) @Max(12)`). 컨트롤러 클래스에 `@Validated` 붙이지 않음 (ADR-039)
- 같은 파라미터는 모든 API 에서 같은 검증 (`month` 는 통계·거래 둘 다)
- `@RequestBody` 에 `@Valid` 빠진 곳 — `grep "@RequestBody" | grep -v "@Valid"` = 0

## 6. 예외 · 응답

- 예외 클래스는 도메인별 (ADR-035). `exception/` 패키지에만
- 핸들러 — 우리 예외는 `e.getMessage()`, 프레임워크 예외·최종 `Exception` 은 고정 문구 (ADR-012)
- 최종 핸들러는 `log.error(..., e)`. `printStackTrace` 0건
- 상태코드 — POST 201 / GET·PUT 200 / DELETE 204. 전부 `ResponseEntity.status(HttpStatus.X).body(...)`

## 7. 프론트 (ADR-033)

- 경로는 절대경로 — `grep -rn "\.\./" static` = 0
- 색상은 `common.css` 변수만
- 사용자 입력은 `escapeHtml` 거쳐 `innerHTML`

## 8. 흔적 · 비밀값

- `TODO`·힌트 블록·임시 엔드포인트·`System.out`·`console.log` — 기능 완료 시 0건
- 비밀값은 `${ENV}` 만. `grep -n "password\|secret" application*.yml` 에 리터럴 없음
- 로컬 메모(`docs/로컬환경.md`) 미추적 — `git ls-files | grep 로컬환경` = 0

## 9. 문서 ↔ 코드

- 지운 엔드포인트·스크립트가 docs 에 남아 있지 않은가
- 진행상황.md 의 파일명·단계 상태가 실제와 같은가
- 새 결정은 ADR 로, 뒤집힌 결정은 "폐기" 표시

## 10. 모양 (포매터 — `.editorconfig`)

- 자바·XML 탭, JS·HTML·CSS 스페이스 4, YAML 스페이스 2
- 위임받은 코드를 붙여넣기 전에 IDE 포맷 한 번 (Ctrl+Shift+F)
- 기존 혼재 파일 일괄 정리는 Sprint 1 전체 리뷰 때 한 커밋으로
