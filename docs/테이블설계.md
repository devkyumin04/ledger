# Ledger V3.0 테이블 설계

18개 테이블. 실제 DDL은 `src/main/resources/db/migration/V1__init_schema.sql`.

## 마이그레이션 정책

- 아직 실제 환경에 한 번도 적용되지 않은 단계라 DDL은 `V1__init_schema.sql` 하나로 통합
- V1을 최초 적용한 이후 스키마 변경이 생기면 V2, V3 순서로 새 마이그레이션 파일 추가

## 공통 관례

| 컬럼 | 타입 | 의미 |
|---|---|---|
| `USE_YN` | CHAR(1) DEFAULT 'Y' | 소프트 딜리트 |
| `CREATED_AT` | DATETIME DEFAULT CURRENT_TIMESTAMP | 생성일시 |
| `VERSION` | INT DEFAULT 0 | 낙관적 락 (거래 테이블만) |

|---|---|---|---|

| PROVIDER_USER_ID | VARCHAR(100) | NN | |

**제약**
- `(PROVIDER, PROVIDER_USER_ID)` UNIQUE — 동일 소셜계정 중복 연동 방지
- `(USER_NUM, PROVIDER)` UNIQUE — 한 회원이 같은 제공자를 두 번 연동하는 것 방지

**주의** — 이미 이메일/비밀번호로 가입된 계정과 동일 이메일의 소셜 로그인 시도는 자동 연동 처리하지 않음.
